# Think Mybiz Tech website — source

This repo **is** the live site. `main` auto-deploys to `public_html` on thinkmybiztech.com (Hostinger Git auto-deployment). Never upload files manually in hPanel.

## Editing pages

All HTML pages are generated by `_src/build.py` (shared header, footer, navigation and page content). Do not hand-edit the generated `index.html` files — edit `build.py` and rebuild:

```bash
python3 _src/build.py      # regenerates every page, sitemap.xml, robots.txt, favicon.svg and .htaccess at the repo root
git add -A && git commit -m "…" && git push   # push to main = live within seconds
```

Hand-edited files (not generated): `assets/css/style.css`, `assets/js/main.js`, `api/*.php`, `assets/img/*`, `assets/fonts/*`.

## Server-side pieces (PHP on Hostinger)

| File | Purpose |
| --- | --- |
| `api/enquiry.php` | Contact form endpoint. Validates, blocks spam (honeypot, timing, 5/hour per IP), appends each enquiry to `../tmbt_private/enquiries.jsonl` (outside `public_html`) and emails info@ with Reply-To = client. |
| `api/cms.php` | Read-only WordPress client with a 10-minute cache in `../tmbt_private/cache/`. Not directly reachable. |
| `insights/article.php` (generated) | Server-renders each post at `/insights/<slug>/` with title, description, canonical and BlogPosting schema. |
| `api/sitemap-insights.php` | `/sitemap-insights.xml` — every published post, listed in `robots.txt`. |

Contact details, WhatsApp number and social profile URLs are constants at the top of `build.py` (`PHONE`, `TEL`, `WA_NUMBER`, `SOCIAL`). Add a social URL and rebuild to show it in the footer and in the Organization schema.

`/_src/` is blocked from public access by `.htaccess`.
